## 每天怎么学

工作日：早通勤20分钟理解概念，午休10分钟闭卷回忆，晚通勤20分钟案例应用。
忙碌时只做5分钟最低任务。晚上到家不增加必修任务。
周末两天合计3～4小时：周六约2小时实践，周日约1小时复盘写作，可选加1小时。

可在学习对话中提交答案，由助手整理归档；也可复制[作业模板](templates/assignment.md)自行填写。
未提交答案不代表已掌握；中断后不累积补课。
